## Reviewer question and assumptions

Please review whether **A1's materialization, ordering and resource ownership**
are correct given an already-valid, object-bound upper-layer authorization.
This is not a request to approve the full M0 design. The current caller proof
contains object name and written/schema widths; upstream callers remain
responsible for relationship, schema/snapshot, eligibility and complete object
validation. A1 does not establish that these assumptions are sufficient across
clone, recovery, old objects or remote execution. Those are unresolved A2
design and qualification items.

The shared ObjectIO missing-column guard remains in place and default behavior
is not relaxed. Physical loads on the A1 mapping path remove the M0 proof from
the physical read context; an unexpectedly missing physical column fails.
Search/fused TopN, pruning/ranges, statistics/COUNT, independent classification,
historical compatibility and remaining direct ObjectIO consumers are A2, not
claimed as migrated by this patch. No new persisted field, wire protocol,
global cache, performance or mixed-version claim is made.

## A1 behavior and resource contracts

The engine mapping separates physically present columns from the authorized
missing suffix, checks the current object's block metadata, derives physical
row count and reconstructs outputs in requested order. It is call-local and
bounded by the requested projection. CN block-copy/read, selected-row/late
materialization, ordinary TopN payload materialization and the TN persisted
column loading entry are the connected consumers; this list does not include
the A2 fused Search/TopN qualification or pruning paths.

| Path | Success owner | Partial failure / cancellation owner |
| --- | --- | --- |
| CN cached vectors | The returned callback frees transferred vectors then releases the physical I/O lease. | Physical loader releases its I/O vector and partial cache on decode failure; canceled/failed call returns no callback. |
| Selected-row destinations | Caller owns destinations and returned mask; physical loader retains then releases the I/O lease before returning. | Caller frees any completed destination prefix; A1 releases mask on later NULL-materialization failure. Read cancellation releases acquired I/O results. |
| TN copy | Caller closes copied and synthesized vectors; physical I/O lease is released inside the physical loader. | Physical loader closes constructed copies and releases its I/O vector on decode failure; no result or lease escapes. |
| TN borrow | Caller closes vectors and then calls returned lease-release callback. | Physical loader closes already constructed borrowed wrappers and releases I/O vector on later decode failure; no result or lease escapes. |

The tests cover explicit file-service read cancellation after leases are
acquired and entry-cancellation; they do not establish arbitrary asynchronous
cancel timing inside every downstream decoder or whole distributed pipeline.
